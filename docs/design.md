# CR8VERESEARCH DESIGN SYSTEM

## PRODUCT CHARACTER

cr8veResearch is a private digital research studio.

The interface combines:
- research laboratory
- archival system
- digital creative studio
- personal notebook

It should feel intentional, quiet, tactile and intelligent.

It should not feel like:
- social media
- a generic SaaS dashboard
- an AI chatbot
- a productivity app
- a hacker terminal

## TYPOGRAPHY

### HEADERS

Headers use uppercase typography.

Example:

REFERENCE
RESEARCH SPACE
RELATED THREADS

### NOTES

User-authored notes use lowercase typography.

Example:

this image feels like a machine designed for a civilization
that disappeared.

### COMMENTS

Comments and marginal annotations use `//`.

Example:

// why does this feel nostalgic?

// investigate the relationship between ritual and machinery.

Comments should feel like annotations in a research notebook.

## INFORMATION HIERARCHY

Prioritize:

1. Reference
2. User interpretation
3. Context
4. Connections
5. Metadata

The interface should never overwhelm the reference itself.

## CORE PRINCIPLE

The interface should support investigation rather than demand attention.

Avoid unnecessary:
- notifications
- badges
- engagement indicators
- animations
- decorative UI
- gamification
